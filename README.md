# Prasanna Devi S --- 3D Interactive Portfolio

A modern, responsive personal portfolio website built with HTML, CSS and
JavaScript. The design uses a futuristic dark interface, animated
visuals, glassmorphism-style cards and an interactive 3D skills globe.

## ✨ Features

-   Modern dark futuristic UI
-   Responsive desktop, tablet and mobile layout
-   Animated portfolio preloader
-   Smooth scroll navigation
-   Active navigation state while scrolling
-   Animated typing effect
-   Interactive 3D hero/tilt effects
-   Ambient glow and mouse-parallax effects
-   Scroll reveal animations
-   Interactive 3D skills globe
-   Mouse drag and touch/swipe support
-   Automatic globe rotation
-   Momentum after dragging
-   Transparent depth-based skill labels
-   Profile photo on the landing page
-   About, Experience, Projects, Skills and Contact sections
-   Client-side contact form interface

## ▶️ Run Locally

No framework or build process is required.

1.  Keep all project files in the same folder.
2.  Open `index.html` in a modern browser.

Recommended browsers:

-   Google Chrome
-   Microsoft Edge
-   Brave
-   Firefox

## 🌐 Deploy Online

This is a static website and can be deployed using:

-   Netlify
-   GitHub Pages
-   Vercel
-   Cloudflare Pages

Upload the complete project:

``` text
index.html
main.js
stylesheet.css
Prasanna_Devi.jpg
```

Do not upload only `index.html`, because the page depends on the CSS,
JavaScript and profile image.

## 🖼️ Change the Profile Photo

Place the new image in the same folder and update the filename in
`index.html`.

Example:

``` html
<img src="Prasanna_Devi.jpg" alt="Prasanna Devi">
```

If the image is renamed to `profile.jpg`:

``` html
<img src="profile.jpg" alt="Prasanna Devi">
```

The filename must match exactly.
